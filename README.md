# OpenWeatherMap API Weather Forecast

5-day Weather Forecast including descriptions and temperatures

## About

To use the OpenWeatherMap API, you need an API key.
Create one [here](https://home.openweathermap.org/users/sign_up) and create an '.env' file containing your key:
'APIKEY=Your-API-Key'

## Features

- Asks the user what city, state (optional), and country
- Returns a 5-day preview for what the weather/temp (in F°) will be like each day at 12:00 PM
- Converts location into latitude and longitude components, which are printed to the terminal

## Requirements

Make sure you have the following dependencies installed:

- python3
- requests
- dotenv
